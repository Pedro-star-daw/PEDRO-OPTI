# PEDRO OPTI

PEDRO OPTI is a lightweight Windows performance optimizer built in Python. It gives you a clean desktop interface for running common, low-risk performance tweaks such as cleaning temporary files, flushing DNS, enabling high-performance power mode, and toggling basic visual effects.

Important:
- This tool is intended for Windows systems.
- Some actions require Administrator privileges.
- It includes safe, reversible tweaks and will not intentionally damage the system.

Features:
- View live CPU, RAM, and disk usage
- Clean temporary files and cache
- Flush DNS cache
- Switch to High Performance power mode
- Reduce visual effects for better responsiveness
- Run all safe optimizations in one click
- Simple GUI built with Tkinter

Quick start:
1. Install Python 3.10+
2. Open a terminal in the project folder.
3. Run:
   python main.py

Notes:
- For registry-based tweaks, Windows may prompt for admin rights.
- If you are unsure about a change, skip it and use the individual actions.
