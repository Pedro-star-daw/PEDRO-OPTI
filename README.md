# PEDRO OPTI

PEDRO OPTI is a legitimate Windows performance optimization tool built in Python. It is designed for safe, reversible tweaks that help remove junk files, reduce startup clutter, improve responsiveness, and optimize Windows power and visual settings.

What it does:
- Cleans temporary files and browser/cache folders
- Flushes DNS cache
- Sets a better Windows power plan when available
- Adjusts visual effects for higher responsiveness
- Lists and disables startup programs safely with a restore option
- Keeps a backup before disabling startup items

Important:
- This app is intended for Windows systems.
- Some actions may require administrator rights.
- Startup changes are reversible through the restore feature.

Quick start:
1. Install Python 3.10+
2. Open a terminal in the project folder
3. Run:
   python main.py

Recommended usage:
- Run the Cleanup and Power Optimization actions first
- Review startup apps and disable only unnecessary ones
- Use Restore Startup if you want to undo any change
